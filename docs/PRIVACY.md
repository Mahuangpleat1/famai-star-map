# 隐私说明 · 法脉星河

更新：2026-09-17。以下描述适用于本仓库代码；实际部署者的访问日志和模型服务条款需另行查看。

## 本地保存

应用无需账号。导入的资料文本、抽取结果、题目、错题和 Obsidian 映射保存在浏览器 IndexedDB；收藏、笔记和界面偏好保存在 localStorage。选中状态等可能包含在 URL hash 中，分享链接前请检查内容。

关闭浏览器通常保留这些资料，但浏览器清理、存储回收或设备故障可能导致丢失。没有云端备份。JSON 导出包含资料正文和学习记录，应按个人文件妥善保管。

## API Key 与模型请求

- API Key 默认仅保存在当前页面内存中，刷新或关闭页面后需重新输入。
- 主动勾选“在此浏览器记住 Key”才会写入 IndexedDB。该存储未加密，同源脚本及拥有相应权限的扩展可能读取它；内存中的 Key 也无法防御恶意脚本。
- 旧版已保存且没有记住授权标记的 Key，在首次读取配置时迁移到当前页面内存并从持久记录中清除。
- baseURL、模型名和生成参数会本地保存。JSON 备份省略 Key 和记住授权；恢复设置会清空当前 Key，避免把旧 Key 发往备份里的新地址。
- 点击分析资料时，浏览器会把该资料原文、已有概念摘要和请求所需 Key 发送到你配置的模型服务。
- 点击生成学习报告时，只发送你选中的成功抽取摘要、关系、引用及来源 id/文件名，不重新发送原始资料正文；报告也不会重新核验原文。
- 模板题目在本地生成；如主动使用 AI 判题，会发送作答与相关概念信息。服务商如何处理或保留数据由其政策决定。

先核对服务地址，只发送已获授权且适合交给该服务处理的内容。项目不提供后端 Key 代理。

## 网络与诊断

应用不主动发送错误、性能指标或使用统计，不支持通过旧版 localStorage 日志地址开启上报，也不引入分析 SDK。错误仍可能显示在本地控制台；发送问题报告前请清除正文和凭证。

加载页面及 Service Worker 更新需要请求托管站点静态资源。部署平台可能记录 IP、请求时间和 User-Agent 等访问日志。主动打开来源链接会访问相应网站。应用代码不写 Cookie，但托管平台或模型服务的行为不由本仓库保证。

Service Worker 只处理本站部署路径中的页面与静态资源，不缓存模型请求。离线只能使用已加载并缓存的资源；首次打开、未缓存页面功能以及在线模型调用仍需网络。

## 导出、删除与反馈

工作台可导出 JSON 备份，再在另一浏览器恢复；Key 不随备份迁移。导入恢复按记录 id 合并，覆盖选项不会自动清空其余记录。删除当前站点的浏览器存储可移除资料与设置；本地文件和已交给外部模型的数据需分别处理。

一般问题可在实际项目仓库 Issues 中提出，不要附带真实 Key 或私密资料。安全问题按 [安全基线](SECURITY.md) 的披露方式处理。
