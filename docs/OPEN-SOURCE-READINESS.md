# 开源准备与验收记录

本记录对应 2026-09-17 整理的当前源码版本。项目使用仓库中的 AGPL-3.0 许可证；公开仓库为 [pallwalt/famai-star-map](https://github.com/pallwalt/famai-star-map)，发布内容采用独立源码包；本次不包含公网网站部署。远端检查以 [GitHub Actions](https://github.com/pallwalt/famai-star-map/actions) 的实际结果为准。

## 已实现的学习流程

- 配置 OpenAI 兼容 API 地址、模型和自己的 Key。默认仅当前页面记住 Key，刷新即清除；可明确选择在此浏览器持久保存。备份不包含 Key。
- 导入文本、Markdown、可提取文字的 PDF，或直接粘贴资料。原文先保存到浏览器，主动点击分析后才调用配置的服务。
- 长文分块分析，按部门法整理概念并建立关系；结合已有概念推断跨资料关系。稳定概念 ID 区分不同资料中的同名概念。
- 在星图中查看、审核和编辑概念与关系，合并概念及撤销使用原子存储更新；编辑关系后同步刷新详情和星图。
- 选择已分析资料，生成带来源索引的学习报告并下载 Markdown；保留 Obsidian 导出、JSON 备份和本地模板练习。
- 抽取和报告支持取消、超时与失败提示；拒绝过大输入、无效关系和被服务截断的回答，不把不完整结果当作成功。

预置的 610 个节点、969 条关系及 11 个部门法星系是学习底图。AI 输出为待核实的学习内容；报告依据已抽取摘要与关系生成，不重新核验法律原文。

全量浏览器测试运行期间，在开发服务器的监听目录内解压源码触发了 Vite 对 tsconfig.json 的全页重载，使一个导航场景的计数归零。停止并行解压后保留原断言定向复验通过；未把首次全量执行记录改写为全绿。初轮测试另发现工作台初始化的空态误报，现已补加载状态与回归测试；手机操作先正常关闭新手引导。

浏览器学习流程使用合成 Key、教学资料和拦截的 AI 响应，检查导入与粘贴、跨资料关系、报告下载、备份脱敏、刷新后数据保留及会话 Key 清除。没有发送真实法律资料，没有使用真实付费 Key。任意第三方服务的 CORS、模型 JSON 输出质量、成本与可用性尚需使用者按实际配置验证。

## 发布用源码

执行 `npm run package:source` 生成：

- `release/famai-star-map-source.zip`：可用于新建 GitHub 仓库的源码。
- `release/famai-star-map-source.manifest.json`：逐文件及压缩包 SHA-256 清单。

打包器仅收录指定源码、配置、合成示例及公开文档，排除 `.git`、依赖、构建产物、测试产物、内部工作记录、`.env*` 和参考素材。原目录与旧历史保留在本地；本次没有完成旧 Git 历史的逐对象审计，因此发布入口是此源码包，而非直接推送旧历史。

当前打包内容检查未发现高置信度真实密钥格式、私钥块或个人机器绝对路径；这不是对任意未来加入文件的秘密或版权来源保证。第三方参考视频截图未纳入发布包；公开包保留的应用截图来自本项目界面。

将源码包解压后的内容放入新建仓库，再按 [README](../README.md) 安装和验证。CI 会执行代码检查；GitHub Pages 的 Deploy 仅手动触发，不随 push 自动发布。需要公网网站时，按 [部署指南](DEPLOYMENT.md) 配置实际目标并在发布后复验。

## 当前范围

无云账号、多设备自动同步、服务端 Key 代理或扫描件 OCR；浏览器清理站点数据会删除本地记录。文本每份最多 20 万字符，PDF 文件最多 100 MB；已有概念与报告摘要上下文设有明确大小限制。细节见 [使用说明](../README.md)、[隐私说明](PRIVACY.md) 和 [安全说明](SECURITY.md)。
