# 使用说明与学习边界 · 法脉星河

更新日期：2026-09-17

法脉星河是可自行运行的开源法律学习工具。代码许可见根目录 [LICENSE](../LICENSE)，数据流见 [隐私说明](PRIVACY.md)。本文件说明项目用途，不承诺托管服务、运营通知或特定争议处理机制。

## 学习用途

预置星图、AI 抽取、关系推断、报告和练习用于整理与复习。它们可能不准确、遗漏或过时，不构成法律意见，不是权威法律检索库。模型置信度不是正确率。需要时请核对原始资料、官方文本及其效力状态；项目不会自动验证这些内容。

部分预置概念仍有待人工核实的来源标记。公开来源链接说明整理依据，不代表来源机构认可本项目，也不保证链接长期可用。

## 资料与服务商

请仅导入你有权处理的资料，发送给 AI 前检查并移除不必要的个人信息。上传先保存在当前浏览器；点击分析后会发送原文与既有概念上下文，点击生成报告会发送抽取内容及来源名称，到你配置的 AI endpoint。服务商的数据处理政策、使用条件和费用由其规定。

项目不取得你所导入资料的所有权，也不能因资料被上传而向别人授予其使用权。AI 输出的使用条件需结合所选服务商和原始资料的要求判断。

## 许可范围

本项目可授权的软件代码按 AGPL-3.0 提供。第三方库保留各自许可证；引用的法律文本、教材、网站内容和其他第三方材料不因进入项目而被重新许可。不得把缺少再分发授权的第三方参考图片、视频截图或私人学习资料混入公开仓库。源码发布包排除了本地 `references/` 研究材料。

## 数据保管

浏览器清理站点数据、隐私模式退出或设备故障都可能丢失学习资料。请按需导出备份；备份包含资料正文和学习记录，请妥善保管。备份不包含 API Key。更换设备、浏览器或站点地址后，需要导入备份并重新配置密钥。

软件按 LICENSE 所述条件提供。没有维护期限、永不中断或数据恢复的承诺。清除资料可使用浏览器的站点数据管理；操作前先核对备份。
